SUR WINDOWS 10 ET 11

Deux méthodes simples

Utilisez uniquement la méthode convenue avec moi avant le dépannage.

1
MÉTHODE CONSEILLÉE

Assistance rapide Microsoft

Déjà disponible sur de nombreux PC Windows. Aucun logiciel supplémentaire à télécharger dans la plupart des cas.

  1. Sur votre clavier, appuyez en même temps sur Ctrl + Windows + Q. Vous pouvez aussi rechercher « Assistance rapide » dans le menu Démarrer.
  2. Sur votre écran, repérez la zone « Code de l’assistant ».
  3. Saisissez le code à 6 chiffres que je vous communique pendant notre échange, puis validez.
  4. Choisissez « Autoriser » pour partager l’écran. Si une demande de contrôle apparaît, autorisez-la seulement après notre accord.
Aide officielle Microsoft ↗
2
SOLUTION DE SECOURS

DWService

Si Assistance rapide ne fonctionne pas, nous pouvons utiliser une connexion temporaire depuis votre navigateur.

  1. Cliquez sur « Télécharger DWAgent » ci-dessous, depuis le site officiel DWService.
  2. Ouvrez le programme téléchargé, puis choisissez « Exécuter » (et non « Installer »).
  3. Le programme affiche un identifiant et un mot de passe temporaires. Communiquez-les-moi uniquement pendant notre échange.
  4. Je me connecte pour vous dépanner. Fermez DWAgent à la fin pour terminer la session.
Télécharger DWAgent ↗Aide DWService ↗

Votre sécurité avant tout

N’autorisez jamais un accès à distance à la demande d’un inconnu. Nous devons avoir convenu ensemble de l’intervention au préalable. Ne transmettez aucun code, identifiant temporaire ou mot de passe dans le formulaire de contact.

Vous gardez la main : vous pouvez interrompre le partage ou fermer le programme à tout moment. Aucune installation d’accès permanent n’est demandée pour ces deux méthodes.
